# 📡 Temperature Compensated Speed of Sound Measurement

A portable embedded system that measures the speed of sound using ultrasonic time-of-flight while compensating for ambient temperature using an LM35 sensor.

Built using Arduino Nano, HC-SR04, LM35, custom PCB, and a custom-designed 3D printed enclosure.

---

## Features

- Temperature compensated speed measurement
- Real-time LCD display
- Custom PCB
- Custom 3D printed enclosure
- Battery powered
- Embedded C++ firmware
- Experimental validation

---

## Hardware

- Arduino Nano
- HC-SR04
- LM35
- 16x2 LCD
- LM7805
- LEDs
- 9V Battery
